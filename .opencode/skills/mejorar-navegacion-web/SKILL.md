# Mejorar navegacion web

## Cuándo usar
Cuando se necesita optimizar la navegación de un sitio web existente o crear una buena desde cero.

## Checklist de navegación

### Menú principal
- [ ] Menú definido por el Mapa del Sitio V2 de UX/UI (fuente de verdad 15/09/2026): 9 items
      aprobados; antes del cambio la regla era máx. 4-5 items
- [ ] Logo enlazado a home (sin botón "Inicio")
- [ ] Menú fijo (sticky) al hacer scroll
- [ ] Item activo resaltado (peso/opacidad/color, subrayado o tachado) — no exagerar: 1-2 opciones
- [ ] Item en hover resaltado (mismas opciones)
- [ ] Botón hamburger si hay más de 5 items
- [ ] Menú en páginas de una sola página (landing/long-form) enlazando a secciones

### En páginas largas
- [ ] Navegación por puntos (dots) con tooltips de sección
- [ ] Barra de progreso de scroll (solo si la página mide más de 3-4 pantallas; color contrastante)
- [ ] Botón "Volver arriba" al final
- [ ] Breadcrumb navigation para jerarquía (sitios grandes con muchas secciones/categorías)

### Feedback al usuario
- [ ] Barra de carga al cambiar de página
- [ ] Botones CTA con color llamativo
- [ ] Botón secundario transparente para acciones menores

### Contenido
- [ ] Botón "Show more" para listas largas
- [ ] Dropdowns para submenús
- [ ] Tabs para contenido relacionado
- [ ] No dead-ends: repetir CTA o enlazar artículos similares al fondo

### URLs
- [ ] URLs descriptivas y limpias (no códigos del sistema tipo `/page4652188.html`)
- [ ] Separar palabras con guiones: `/about-us`
- [ ] Anclas (anchors) con nombres claros en landing: `#about`, `#contacts`
