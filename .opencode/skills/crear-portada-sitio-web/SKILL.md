# Crear portada sitio web

## Cuándo usar
Cuando se necesita diseñar la portada  de un sitio web.

## Principio rector
El texto es lo primero, la imagen solo lo soporta. La imagen establece el estado de ánimo; el texto entrega el mensaje. No hace falta mostrar lo que ofreces en la portada.

## Flujo de trabajo

### 1. Definir el mensaje
- Clarificar qué debe transmitir la portada (3-5 palabras clave)
- Identificar el público objetivo
- Establecer tono (profesional, casual, artístico, etc.)
- Decidir si la imagen representa el servicio directa o indirectamente

### 2. Elegir imagen
- Buscar imagen que transmita el mensaje y el estado de ánimo correcto
- Verificar que no haya caras que queden cubiertas por texto
- Asegurar que la imagen complemente, no compita con el texto
- Un único objeto sobre fondo neutro facilita la composición
- Formato: JPG, 1680×900 px, 72 dpi, RGB

### 3. Colocar el texto (3 métodos)
- **Área despejada**: texto en el centro de la foto, vacío de detalles
- **Formas simples**: texto sobre un fondo uniforme (pared, cielo)
- **Elementos menos importantes**: texto en el lado opuesto del sujeto (sujeto a la derecha → texto a la izquierda); si la persona está en el centro, bajar el texto al área del cuerpo

### 4. Ajustar el fondo
- Si el texto es ilegible por detalles, oscurecer con gradiente (opacidad 20%-70%+ según el brillo)
- No exagerar: si el filtro negro deja el cover sombrío/sucio, cambiar de foto o **tonificar con color** (marca, paleta del sitio, o color que combine con la imagen)
- Cubiertas blancas para fotos de alta luminosidad (tecla alta) + texto oscuro/color

### 5. Aplicar color
- Regla 90/10: un color primario (90%) + un acento (10%)
- Colorear fondo y texto con cuidado de evitar el aspecto chillón
- Un color brillante para el título junto con filtros de fondo ayuda al "right feel"

### 6. Verificar responsive
- Revisar en desktop (≤980px) y mobile (0-980px)
- Si un elemento importante queda cubierto en mobile, usar dos bloques separados (desktop/mobile)
- Verificar en pantallas de baja resolución

### 7. Herramientas útiles
- Coolors, Materialpalette, ColorHunt para paletas de color
- Tilda: "Filtro de color de inicio/final" para ajustar opacidad
- Tilda: "Visibilidad en dispositivos" para versiones mobile/desktop
- Stock CC0: Unsplash, Pexels, Stocksnap, Rawpixel
